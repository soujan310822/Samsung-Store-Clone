# Samsung Store Clone

A front-end clone of the Samsung Store website built using **pure HTML and CSS**. This project was created to practice front-end web development, improve layout skills, and recreate a modern, responsive user interface.

## Features

* Modern Samsung-inspired UI
* Responsive design
* Navigation bar with mega menu
* Product sections and banners
* Clean and organized HTML & CSS

## Technologies Used

* HTML5
* CSS3
  
## Drawbacks
*Website is not Responsive(may be i will work on it in future)
